L ≡ Lν(tdec) at the selected observing band.
Lref = 1032 erg s⁻¹ Hz⁻¹.

Settings
Optical survey mode

Within-night cadences require a detection window ≤ tnight. Longer cadences must be whole days. The observing budget requires flive ≤ fnight = tnight/24 h.

Color by detection regime

Colors identify the dominant detection regime shown in the legend.

Exact rate mode

Integrates the rate over viewing angle. With this off, the rate uses the dominant-term approximation.

Measure detection window from the peak

Requires the selected detection window after the peak: t+ − tp ≥ (i−1)·tcad, or ≥ i·tcad when that window is selected.

Rise cut (srise): random start time

Averages the rise cut over a first observation uniformly distributed within one cadence after the peak. When off, the first observation is placed at the peak. No effect when srise = 0.

Fade cut (sfade): random start time

Averages the fading cut over a first observation uniformly distributed within one cadence after the peak. When off, the first observation is placed at the peak. No effect when sfade = 0.

tOH approximation

Neglects overhead in the exposure-time calculation while retaining texp > tOH as a validity condition.

Detection window spans i·tcad

Uses i·tcad for the required detection window instead of the (i−1)·tcad between i detections. In optical mode, this window must fit within tnight.

Luminosity function

Uses dℛ/dL = (𝒜/Lref)(L/Lref)α for L > 0, where L ≡ Lν(tdec). The detected rate is finite for −5/2 < α < −1; the total intrinsic rate and population median are undefined. 𝒜 replaces ℛ. The frequency, electron and magnetic energy fractions, and flux override are inactive because the luminosity function specifies the spectral luminosity.
