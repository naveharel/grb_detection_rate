Settings
Optical survey mode

Requires ≥ i detections in one night (intra-night) or a single detection per night across nights (inter-night). Activates tnight and defines fnight = tnight/24 h; sub-night (intra-night) cadences are rescaled by fnight, per-day (inter-night) cadences are unchanged. Requires fnight ≥ flive.

Color by detection regime

Tints the surface by dominant regime: warm = flux-limited (DEuc), cool = cadence-limited (Di), gray = singly-limited (Ddec). Brighter = higher range.

Exact rate mode

Integrates Rdet over all viewing angles q ∈ [0, qnr] (thesis Eq. 39) instead of the dominant-term approximation — slower, but exact. Unlocks the refinements below; the first time it is switched on they all turn on together, and each can then be toggled independently.

Include t− ≈ ton

Measures the detectability window from the light-curve turn-on ton ≈ tp (window start t− ≈ ton) instead of from the burst: t+ ≥ tp + i·tcad, so off-axis events must stay above the limit for the full duration after they peak (the legacy criterion credits detections to the pre-peak interval, where the off-axis flux is negligible). Suppresses the marginal off-axis population and moves the detected q-median on-axis. By default (“Detection window spans i·tcad” off) gives the corrected criterion t+ − tp ≥ (i−1)·tcad; with that toggle also on, instead gives t+ − tp ≥ i·tcad.

Rise cut (srise): random start time

Applies the srise cut as a uniform random observation-start survival weight (only a fraction of bursts pass, depending on when the survey happens to catch them). Off: the best-case hard boundary (first detection assumed at the peak, as in the dominant-term mode), which raises the rate. No effect when srise = 0.

Fade cut (sfade): random start time

Applies the sfade cut as a uniform random observation-start survival weight. Off: the best-case hard boundary, which raises the rate. No effect when sfade = 0.

tOH approximation

Drops tOH from the exposure formula to enable closed-form optimal strategies, while still enforcing texp > tOH as the validity boundary.

Detection window spans i·tcad

Adds one extra waiting gap: counts the required detectability duration as i·tcad instead of the i−1 gaps between the i detections (default, off). Enters wherever a hard window is used: qi, Di.

Luminosity function

Draws each burst's intrinsic luminosity L ≡ νLν(1 day) from a power law φ(L) ∝ Lα on [Lmin, Lmax] instead of the single fiducial L0. φ is normalized, so the total burst rate is unchanged: the distribution only redistributes brightness. Faint bursts lose detection volume as L3/2 while bright ones saturate at the survey depth or the DEuc wall — the Malmquist asymmetry no single luminosity can mimic. While on, the pure-normalization controls (log εe, log εB, and the Fν override) no longer affect the rate; shape parameters (p, Ek,iso, n0, Γ0, θj, ν, DEuc) still do.
